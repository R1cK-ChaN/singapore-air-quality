# 使用说明

[返回首页](../README.md)

以下命令均在仓库根目录执行。

先通过 NEA / data.gov.sg 官方 API 下载数据，保存原始 JSON 和清洗后的 CSV，再用 Matplotlib 读取 CSV 绘图。不调用图片生成模型，也不把设计示意值当成观测数据。

## 安装

克隆仓库后，在仓库根目录执行（Python 3.10+）：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

默认字体为京华老宋，下载及本地安装位置见 [字体说明](../fonts/README.md)。所有绘图入口共用 `typography.py`；也可以在 `run` / `plot` / `cards` 命令后加 `--font /path/to/font.ttc`。

## 使用

当前连载采用两张数据卡：第一张为全岛空气地图和最近七天总体日均趋势；第二张为带定位小地图的五区小时对比。默认取新加坡时间今天，自动补抓缺少的历史日期，并刷新当天数据：

```bash
.venv/bin/python air_quality.py cards --date 2026-09-29 --days 7
```

产物在 `output/YYYY-MM-DD/cards/`：`01-island-overview.png/svg`、`02-regional-comparison.png/svg`，以及可核对统计口径的 `daily_summary.csv`。只有两张卡，不输出第三张。每张 PNG 为 1080 × 1440。

仅调整视觉时可追加 `--offline`：不会重新请求空气数据或底图，但要求所选日期的 CSV、当日原始 JSON、对应底图瓦片和标志已缓存。`cards` 由 `cards.py` 实现，`--days` 支持 2–31 天。

### 每日 11:00 版

每日版建议在新加坡时间 **11:05** 启动，执行：

```bash
.venv/bin/python daily.py
```

`daily.py` 自动选择新加坡当天日期。五区 **11:00** 读数全部返回后才生成两张图；未齐时每60秒重查，最多等待60分钟，超时记录失败，不使用更早读数替代。网络故障由抓取层有限重试，仍失败则报告错误。以后补跑也只绘制当天11:00及以前的读数，第二张始终覆盖昨日11:00至今日11:00。

运行时补齐缺失日期，并刷新缓存中不完整的历史日期，避免昨日早上的缓存截断今日曲线。保留已确定的京华老宋、纯白背景、浓度分档颜色、渐变和版式。产物按日期写入上述 `cards/` 目录，同一天重跑更新该目录；`daily_run.json` 记录完成或失败状态，只有 `status=complete` 才表示本次两张图生成并通过尺寸、背景及文件校验。

手动补跑用 `--date YYYY-MM-DD`；离线复现再加 `--offline`（仍要求五区11:00数据齐全）。`--wait-minutes 0` 可立即检查而不等待。原始 CSV 保留11:00以后的数据，截止限制只作用于每日版统计与出图。

定时器需在运行环境中单独配置，例如使用 Codex 定时任务每天在新加坡时间11:05运行上述命令。仓库本身不包含已启用的定时器，克隆不会自动开始任务。使用本地 Codex 定时任务时，电脑须开机、Codex 须保持运行，项目及网络须可用。11:05是启动时间，实际完成时间取决于数据发布和接口响应。

### 两张卡的统计和地图口径

- 第一张的当前数值和地图均取当天 CSV 中最新有读数的小时；若该小时某区缺测，地图显示缺测，不用更早数据替代；五区不齐时不显示总体均值。
- 每个完整小时先对五区等权平均，再对完整一天的 24 小时平均。这等于五区日均值等权平均，是自算的新加坡总体概览，不是官方全国指数，也不按人口或面积加权。
- 历史日期缺少任一区任一小时，就不绘制该日的完整日均值。最后一天若从 00:00 到最新时刻五区读数连续完整，则单独显示空心的截至当前均值，不与完整日均折线相连；中间有缺测则不显示这个临时均值。日均图按数值区间配色，不将颜色解释为日均健康等级。
- 两张卡均使用纯白底色。每个折线数据点、数值注释及其连接线按自身浓度着色：不高于55为绿，高于55至150为黄棕，高于150至250为红，高于250为紫；连接线在穿越边界的位置换色。折线下方使用对应颜色的纵向渐变，靠近折线为24%不透明度，向零值横轴渐淡至透明，缺测处不填充。缺测仍断线，线段交界不是新增观测值。
- 第二张复用第一张的地图标识（上方区域、下方最新读数）与浓度分档图例。地图标识、区域名和右侧最新数值按当前读数配色；历史曲线逐点着色。曲线覆盖最新读数之前的滚动24小时，例如昨日11:00至今日11:00，包含两端共25个逐小时读数，横轴铺满整个窗口。所有区域共享纵轴，缺测不补值，横轴两端注明日期。
- 地图来自 [SLA OneMap](https://www.onemap.gov.sg/apidocs/) 的 Grey 瓦片，使用 Web Mercator 投影；区域位置直接来自 NEA 原始响应的 `regionMetadata.labelLocation`，不是监测站位置或行政区边界。地图采用真实底图加数值标记，不用五个区域值插值出连续污染云层。
- 底图瓦片和 OneMap 标志保存在 `output/_maps/`，`sources.json` 记录底图地址、范围和投影；两张图都保留 OneMap 标志和版权署名。数据与底图是独立来源，底图不是当天卫星云图。首次运行需要网络，重绘可完全离线。

### 单日原有命令

一条命令抓取并绘图；不传日期时，默认使用新加坡时间的昨天：

```bash
.venv/bin/python air_quality.py run --date 2026-09-28
```

分开执行抓取和绘图，改样式时无需重新访问网络：

```bash
python3 air_quality.py fetch --date 2026-09-28
.venv/bin/python air_quality.py plot \
  --csv output/2026-09-28/pm25.csv
```

`fetch` 和 `run` 的 `--out-dir` 指定输出根目录，脚本在其中建立日期子目录。`plot` 的 `--out-dir` 直接指定图表目录；省略时放在 CSV 旁边。

## 产物与口径

默认写入 `output/YYYY-MM-DD/`：

- `source.json`：接口地址、SGT 抓取时间和各页原始响应，保留官方更新时间。
- `pm25.csv`：长表，每行包含观测时间、区域、1小时 PM2.5 浓度（μg/m³）及官方更新时间。
- `pm25-YYYY-MM-DD.png`：1080 × 1440 数据图。
- `pm25-YYYY-MM-DD.svg`：矢量版，文字保存为轮廓，打开设备无需安装字体。

五区按北、南、东、西、中固定排序，分为五张共用纵轴的小折线图。纵轴默认 0–160；高值时以 50 为步长扩展并显示实际刻度，不裁掉峰值。上方数字为所有已获取区域小时读数中的最大值，不是当前值或全国平均。

每天应有 24 小时 × 5 区 = 120 个有效值；不足时标题标注“不完整数据”，未返回或缺测的小时和区域保留为空白并断线，不填零、不插值。真正的零读数仍保留。当天数据可以获取，但不能把截至某时的峰值当作完整全天峰值。接口分页全部读取，重复时间采用官方更新时间较新的版本。

重复抓取同一天会更新该目录（用于反映官方修订）；如需保留每次快照，请使用不同的 `--out-dir`。本地数据和图表默认不进入 Git。

## 来源

- [NEA PM2.5 数据集](https://data.gov.sg/datasets/d_e1058d6974c877257e32048ab128ad83/view)
- [官方 API 文档](https://guide.data.gov.sg/developer-guide/real-time-apis)
- [NEA 烟霾指标与分档](https://www.haze.gov.sg/)

使用 `https://api-open.data.gov.sg/v2/real-time/api/pm25?date=YYYY-MM-DD`，读取 `pm25_one_hourly`。测试访问可不使用 key；如果需要，可通过 `DATA_GOV_SG_API_KEY` 环境变量提供，不写入代码或数据文件。遇到限流或服务暂时故障会有限重试。

这里仅绘制官方浓度观测，不做烧芭来源判断，不混用 PSI、AQI 和 PM2.5。背景分档依据 NEA 的1小时 PM2.5：0–55、56–150、151–250、≥251。官方数据可能后续修订。

## 验证

```bash
python3 -m unittest discover -s . -p 'test_*.py' -v
```

检查分页、SGT 日期边界、数据修订、缺测断线所需的空值、重复 CSV 行、非法浓度、日均与当日临时均值、分档边界和地图投影方向；实际 API 连通及出图另用 `run` / `cards` 验证。
